## About this project

Example content - replace this file with your own project write-up. This is the software entry for
the site generator itself: a static Astro site with Markdown-driven content collections for games,
software and downloads, styled to feel like an old-school personal homepage.

## Why

Corporate portfolio templates all look the same. This project exists to prove that a personal site
can still have a bit of handmade personality while staying fast, accessible, and easy to maintain
through plain Markdown files.

## Stack notes

- Astro content collections with the glob loader
- No client-side framework - just enough vanilla JS for progressive enhancement
- Deploys to GitHub Pages via GitHub Actions on every push to `main`
